A beginner-friendly **4-8-4-1 dense neural network** (TensorFlow/Keras) trained on a small **synthetic** cyber-activity table
(`failed_logins`, `login_hour`, `new_device`, `data_transfer_mb` → `0 = Normal`, `1 = Attack`) and compared with an explainable Decision Tree.
No real accounts, logs or networks were used.

## Repository structure
```
├── data/simple_cyber_activity.csv          # synthetic dataset (100 rows: 70 Normal / 30 Attack)
├── notebooks/Lab3_Neural_Network.ipynb     # main deliverable – run in Google Colab
├── src/lab3_neural_network.py              # same pipeline as a script (needs TensorFlow)
├── src/generate_dataset.py                 # reproducible dataset generator
├── src/build_notebook.py                   # builds notebook + script from one source
├── reference/stub/                         # TensorFlow-free NumPy stand-in (see note below)
├── results/reference_run/                  # curves, tables, console output of the reference run
├── Lab_Report.md                           # written answers for Q1–Q5
└── requirements.txt
```

## How to run
**Google Colab (recommended):** open the notebook, upload `data/simple_cyber_activity.csv`, *Runtime → Run all*.
**Local:** `pip install -r requirements.txt` then `python src/lab3_neural_network.py` (from the repo root; outputs go to `results/`).

### ⚠️ Note on how the reference results were produced
The environment used to prepare this repository had **no TensorFlow and no internet access**, so `results/reference_run/` was generated by running the
unchanged `src/lab3_neural_network.py` against a small **NumPy re-implementation of the same 4-8-4-1 network** (`reference/stub/`: Glorot-uniform init,
Adam, binary cross-entropy, batch 8, Keras-style `validation_split`). Real TensorFlow will give slightly different curves and numbers.
**Run the notebook in Colab and use your own outputs/screenshots for submission**; the notebook prints an interpretation that adapts to your run.
To reproduce the reference run: `PYTHONPATH=reference/stub python src/lab3_neural_network.py`.
